# bilibili-epub-pipeline

把 B 站 UP 主视频的 ASR 逐字稿（Obsidian Markdown 笔记）批量压制成 EPUB 电子书的工具链。

本项目源自对「小约翰可汗」248 篇视频笔记的完整归档实践：Whisper 转录 → 标点恢复 → 段落重排 → 校订 → 压制 EPUB。工具在生产环境跑完全库（两本 EPUB，241 章、1341 张图），脚本里固化的是**实战踩出来的防御逻辑**，不是理想化假设。

## 仓库结构

| 文件 | 用途 |
|---|---|
| `make_epub.py` | 终点站：整个笔记目录 → 两卷 EPUB3（嵌图、实体目录页、NCX/nav 双导航、逐字稿热评全保留） |
| `note_kit.py` | 建笔记工具层：SRT 解析、校订应用、按 cue 边界断段、小节切分、密度校验 |
| `reflow.py` | 段落重排：按 cue 边界 + 1.25×目标字数取最近切点，含加粗闭合修正 |
| `model_punc.py` | 标点恢复核心：funasr `ct-punc` 模型初稿 + 机械修复 + 实义字符铁律断言 |
| `batch_punc.py` | 批量标点三段式：extract（平铺）/ model（一次加载跑全部）/ apply（按偏移写回） |
| `run_batch.py` | 单批一键：备份 → 标点 → reflow → 终检 |
| `verify_batch.py` | 批次终检：标点率 / 段均 / 段末断词 / 叠标点 / 字符守恒 |
| `fix_dup_punct.py` | 全库叠标点清理（`，。` 这类 ASR 拼接伤） |

## 安装

```bash
pip install pillow          # EPUB 生成必需
pip install funasr          # 仅标点恢复流水线需要（会拉 modelscope，首次跑会下模型）
```

## 用法

### 生成 EPUB（最常用）

```bash
python3 make_epub.py \
  --vault "/path/to/知识库/bilibili/小约翰可汗" \
  --assets "/path/to/知识库" \
  --out-dir ~/Desktop
```

- `--vault`：放 `.md` 笔记的目录；`--assets`：素材根目录（`素材库/` 所在处），图片按笔记里的 `![[...]]` 与 frontmatter `cover:` 相对路径解析
- 输出两卷：《硬核狠人与单集》（系列按编号 + 单集按发布时间）、《奇葩小国与神奇组织》（均按编号）
- 图片自动限宽 1024px、JPEG q72 渐进重编码；`--maxw` / `--quality` 可调

**笔记格式约定**：frontmatter 含 `title` / `created`；系列期号写在 H1 标题后缀（`xxx？【硬核狠人23】【小约翰】`）；无系列后缀的视为单集。

### 标点恢复流水线（可选，较重）

```bash
export BILI_VAULT="/path/to/你的笔记目录"
export PY_MODEL="/path/to/装了funasr的python"   # 默认同当前解释器
python3 run_batch.py batch_list.txt c_batch1 c1_   # 批清单：每行一个文件名
```

### 段落重排

```bash
python3 reflow.py --file "某篇笔记.md" --apply
```

## 踩坑记录（精选，全部来自实战）

1. **ct-punc 会静默破坏英文**：拉丁占比 >35% 的段落模型会把单词劈开（`Which` → `W hich`），且空格变化绕过「实义字符不变」断言 → 拉丁占比超阈值直接保留原文。
2. **检测与修复必须同源**：`collapse_dup` / `count_dup` 只允许一份实现，修复端和检测端共同 import。否则同一错正则会让终检和修复一起错（实测 1690 处叠标点漏网，靠人眼发现）。
3. **按行统计，不要 join 后统计**：`''.join()` 拼接会产生跨行假阳性。
4. **先 collapse 再 reflow**：顺序反了段末会落逗号。
5. **reflow 切点**：在 1.25×目标字数范围内取离目标最近的句末点；切点落在 `**` 中间时要把紧随的 `**` 吞掉（加粗闭合修正）。
6. **奇数个 `**` 会错位配对**：转 HTML 前把最后一个降级为字面量。
7. **Markdown 惰性续行**：`> 引文` 后面无前缀的裸文本行，若引文断在句中（行尾是 `，、：` 或行内 `**` 未闭合）要拼回引文，否则按正文段落处理。
8. **SRT 正文是第 10 组**：正则写错组号不抛异常，只会静默拼出一堆数字。
9. **字符守恒报警先查统计口径**：「丢了 262 字」实测是切点把 `**` 劈开、行被 is_para 排除出统计——内容都在文件里。
10. **批量改库前备份、改完逐篇回读**，不能只看脚本报成功（Obsidian 开着会用缓存回写）。

完整踩坑记录见各脚本头部的 docstring。
